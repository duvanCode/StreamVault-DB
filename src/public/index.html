¿Cómo funciona el streaming directo a Google Drive?

Al ejecutarse la copia, el comando pg_dump o mysqldump escribe en la salida estándar (stdout), pasando inmediatamente por un compresor gzip en memoria y transmitiéndose por fragmentos HTTP directo al API de Google Drive. En ningún momento se guarda el archivo en el disco duro del VPS, evitando que se agote el espacio de almacenamiento.

Despliegue en VPS con Dokploy

Instrucciones y configuración para subir este servicio directamente a tu servidor.

Dokploy Compatible

Paso 1: Configurar en Dokploy

1. En tu panel de Dokploy, crea un nuevo Proyecto y añade una Aplicación.
2. Conecta tu repositorio de GitHub / Git o selecciona Dockerfile.
3. Dokploy detectará automáticamente el archivo Dockerfile optimizado que incluye postgresql-client, mysql-client y node:22-alpine.

Paso 2: Montar Volumen Persistente

Para que las configuraciones de bases de datos y el historial no se borren al reiniciar el contenedor, añade este volumen en Dokploy:
• Host Path / Volume: job_db_data
• Mount Path: /app/data

Paso 3: Variables de Entorno (.env)

Configura las variables en la pestaña Environment de Dokploy:

PORT=3000 BACKUP_CRON=0 2 * * * TIMEZONE=America/Bogota DASHBOARD_PASSWORD=tu_clave_secreta # Opcional (si deseas precargar las credenciales sin usar la web): DEFAULT_DB_TYPE=postgres DEFAULT_DB_HOST=172.17.0.1 DEFAULT_DB_PORT=5432 DEFAULT_DB_NAME=mi_base_de_datos DEFAULT_DB_USER=postgres DEFAULT_DB_PASSWORD=mi_password GOOGLE_DRIVE_FOLDER_ID=1A2b3C4d5E... GOOGLE_SERVICE_ACCOUNT_KEY='{"type":"service_account",...}'
